# Smart Ad Auditor 🛡️

An AI-powered tool for auditing advertising campaigns to detect inconsistencies, compliance issues, and visual discrepancies.

## 🚀 Overview
This tool automates the process of checking hundreds of ad creatives against specific business rules and compliance standards using Large Language Models (LLMs) and computer vision.

## 🛠️ Tech Stack
- **Backend**: Python / FastAPI
- **AI**: OpenAI / Anthropic Integration
- **Core Logic**: Custom Audit Engine (based on Ranuk IT's proprietary scripts)
- **Deployment**: Docker-ready

## ✨ Key Features
- **Batch Processing**: Upload multiple ad screenshots for simultaneous analysis.
- **Rule-based Auditing**: Define custom criteria (e.g., "No misleading claims", "Logo visibility").
- **Detailed Reporting**: Receive a structured JSON/PDF report for each ad.
